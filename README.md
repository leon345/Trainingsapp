# Trainingsapp

Gesamt-Repository der Trainingsapp (Intervalltimer und Workout-Tracking).

## Struktur & Branches

- **`main`:** Ursprünglicher OpenCode-Prototyp (Passkey-Auth + Intervalltimer).
- **`gemini`:** Vollständige Neuentwicklung aller Muss-Kriterien mit Google Antigravity / Gemini-Agenten inkl. gemeinsamem Helm-Chart und GitHub Action.
- **Submodule:**
  - `server/` – [TrainingsappServer](https://github.com/leon345/TrainingsappServer)
  - `client/` – [TrainingsappClient](https://github.com/leon345/TrainingsappClient)
